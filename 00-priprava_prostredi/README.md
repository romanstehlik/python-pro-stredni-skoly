# Příprava prostředí

Tato část kurzu představuje programovací jazyk Python a nástroje potřebné pro jeho používání.

Čtenář se seznámí s instalací Pythonu, editorem Visual Studio Code, prací v terminálu a základy verzovacího systému Git.

Instalační postupy jsou uvedeny pro **Windows, Linux a macOS**. Další materiály vycházejí převážně z prostředí Windows 11 a PowerShellu.

## Předpokládané znalosti

Tato část nevyžaduje předchozí zkušenosti s programováním.

Předpokládá se základní orientace v operačním systému a schopnost pracovat se soubory a adresáři.

## Výstupní znalosti

Po dokončení této části by měl čtenář zvládnout:

- Vysvětlit základní charakteristiku jazyka Python
- Nainstalovat Python a ověřit jeho funkčnost
- Připravit VS Code pro programování v Pythonu
- Vytvořit a spustit jednoduchý Python program
- Používat základní příkazy terminálu
- Vytvořit Git repozitář a zaznamenávat jeho změny
- Synchronizovat lokální projekt s GitHubem
