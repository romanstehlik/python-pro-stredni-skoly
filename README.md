# Python pro střední školy

Výukový kurz programovacího jazyka **Python** určený především studentům středních škol technického a IT zaměření.

Kurz postupně rozvíjí znalosti programování, algoritmické myšlení a schopnost samostatně navrhovat a vytvářet aplikace. Materiály jsou vhodné pro školní výuku i samostudium.

*Kurz se bude měnit. Další části boudou postupně doplňovány.*

## Předpokládané znalosti

Kurz začíná od základů a nevyžaduje předchozí znalost Pythonu.

Předpokládá se běžná práce s počítačem. Zkušenosti s algoritmizací, vývojovými diagramy nebo prostředím Scratch jsou výhodou, nikoli podmínkou.

## Struktura výukových materiálů

Kurz je rozdělen do tematických celků, které obsahují jednotlivé lekce.

Každá lekce zpravidla obsahuje:

- **`README.md`** – studijní materiál s výkladem a ukázkami kódu.
- **`cviceni.py`** – praktické úlohy k procvičení učiva.
- **`projekt.py`** – samostatný projekt, pokud je součástí lekce.
